# MP3 Player

A simple MP3 player application built in C# with a Windows Forms GUI.

## Features

- Play, pause, and stop MP3 files
- Playlist management
- Browse and load music files
- Simple user interface

## Project Structure

- `AudioPlayer.cs` - Audio playback functionality
- `Playlist.cs` - Playlist management
- `Song.cs` - Song data model
- `FileManager.cs` - File handling
- `Form1.cs` - Main user interface
- `music/` - Sample music directory

## How to Run

1. Open the project in Visual Studio
2. Build the solution
3. Run the application
4. Add MP3 files using the file browser
5. Play your music

## Requirements

- .NET Framework
- Windows Forms
